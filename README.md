# OpenAVC SDK

Manufacturer integration kit for embedding [OpenAVC](https://github.com/open-avc/openavc) in AV equipment.

The SDK is in early development. There is no installable SDK or supported hardware list yet.

The intended integration lets a product describe its capabilities, report state and accept commands from OpenAVC. Products with suitable hardware can also include the full OpenAVC server to control their own hardware and other equipment.

This repository will contain integration libraries, build tools, examples and manufacturer documentation. The OpenAVC server continues to be developed in the [main repository](https://github.com/open-avc/openavc).
