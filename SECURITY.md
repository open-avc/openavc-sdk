# Security reporting

Report SDK security concerns through
[OpenAVC's private vulnerability reporting](https://github.com/open-avc/openavc/security).
Select **Report a vulnerability** and identify the SDK revision, affected
integration and a reproduction using test data. Reports remain private to the
reporter and maintainers. Do not use a public issue for security-sensitive details.

The SDK is an engineering preview without a versioned release. Include the exact
SDK commit or archive and its recorded OpenAVC core revision. Manufacturers adopt
and qualify corrections through their product's firmware update process; the
SDK does not update installed products automatically.

For ordinary build or integration questions, use the
[integration form](https://github.com/open-avc/openavc-sdk/issues/new?template=integration.yml).
